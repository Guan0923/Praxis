# 消息响应与中断流程验证

日期：2026-09-09。分支：`codex/chat-latency-control`。
基线：`dbf161ec97d90b99ab67a3a1eedf0320ccda1f45`。

## 实现范围

- 普通发送和队列发送立即取走文本与附件引用；失败内容保留并可重试。新会话创建失败也不会丢消息。
- 发送回执不会清空后来输入的草稿。等待回执时，发送按钮与实际发送锁保持一致；暂停不被这个锁挡住。
- 普通发送重试复用原 Turn 和 delivery ID。发送响应丢失后，可重新核对现有操作序号并重试，不需要刷新页面。
- 队列刷新保留正在提交和失败的本地消息，忽略旧查询结果；不同会话的提交回调不会改变当前会话草稿。
- 发送、恢复及相关 SQLite 查询不再阻塞异步请求处理。SQLite 待发布事件不重复保存整个 Turn；前端增量处理不再重新规范化全部历史。
- 模型小块输出不再等待 512 字节读取缓冲填满。模型响应、重试等待、命令工具、MCP 共用现有控制器的中断信号。
- Steer 入队后中断旧操作，剩余工具不再启动；运行中的工具结束后才继续。连续指令逐条应用并确认。
- 有可提交队列时按钮显示“追加指令”，提交后显示“暂停”。暂停优先于未应用指令，未应用消息退回待发。
- 暂停失败有独立错误提示并可重试。界面正常暂停流程等待后端状态，不靠隐藏输出伪装停止。

保留 Redis、SQLite、HTTP/SSE、原端点和运行状态名称，没有新增业务状态体系。

## 实测数据

以下是本机独立测试服务的样本，不是所有模型或电脑的延迟保证。

| 检查 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 小块模型 SSE，后续数据延迟 400 ms | 402.8 ms | 2.4 ms |
| 带约 64 KB 历史的单次 SQLite 待发布事件 | 66,966 字节 | 479 字节 |
| 同一事件的增量内容 | 238 字节 | 238 字节 |

Redis 原本已传增量，重复开销主要在发布前的整份 Turn 存储、还原和投影。没有把待发布事件的缩小说成 Redis 线上数据缩小。
SQLite 单次写入耗时没有稳定改善，不作为提速成果；这里减少的是重复工作和对其他请求的阻塞。

浏览器首轮发送记录：点击后约 13 ms 清空输入，140 ms 到达后端，425 ms 开始创建 Runtime，750 ms 产生首段模型输出，812 ms 首次显示输出。
这些阶段来自同一轮测试。完整旧版浏览器耗时未测；前后对照限于上表的读取延迟和事件体积。

暂停重试成功后，自动化点击至后端与界面确认停止约 426 ms。
独立取消测试中，静默 HTTP 连接约 0.3–0.5 ms 退出；两个原定运行 30 秒的真实命令约 29–33 ms 退出，第三个排队命令未启动；本地 MCP 服务约 22 ms 收到取消并仍可继续调用。

## 验证覆盖

真实浏览器使用构建产物、独立 Uvicorn 端口、真实 Redis 测试前缀和独立 SQLite 目录。模型为本地 HTTP 服务，命令为真实子进程，MCP 为本地 stdio 服务。没有调用付费模型、修改用户配置或重启现有服务。

- 新建会话发送、立即清空和连续输入。
- 页面刷新后重新连接正在运行的任务，用户消息不重复。
- 队列提交、steer 中断旧模型连接、暂停后再次发送。
- 丢弃一次暂停请求，确认后端仍在运行，显示失败后重试成功。
- 后端已接收消息但浏览器丢失回执，重试原 ID，保留新草稿。
- 旧会话请求延迟返回时切换到新会话，新草稿不变，旧请求在原会话完成。
- 连续两条 Redis steer 按顺序应用一次；真实 HTTP 暂停与 steer 竞争，未应用消息保持待发。
- 静默响应头、静默 SSE、静默 JSON 响应体；小块输出不等响应结束。
- 长命令实际结束、排队命令不启动、本地 MCP 服务收到取消。
- Redis 事件去重、顺序和恢复；失败发送、重复点击、队列旧响应等针对性回归。
- 桌面 1365×900、窄屏 390×844 截图检查。

针对性后端测试合计 167 项通过，另有 5 项现有 MCP v1 测试因缺少独立 v1 环境跳过。前端 112 项通过，类型检查和构建通过。没有将本轮开始前的 45 项基线重复算作新增验证。

## 限制

- 中断不能撤销已经发生的文件写入或外部操作。
- 真实验证覆盖已建立的本地 HTTP 连接。远端 DNS、TCP/TLS 建连阶段的及时取消未验证，仍可能等待底层连接返回。
- MCP 已验证本地调用退出和配合取消的测试服务。任意第三方 MCP 服务是否停止外部工作仍取决于服务端；关闭客户端调用不能证明外部操作被撤销。
- 沙箱测试使用显式测试启动器运行真实子进程，未修改、重启或重新认证用户的 Windows Broker；本次不是沙箱隔离能力复测。
- 构建保留原有大包体积警告；没有扩展为前端拆包改造。

修改没有提交、合并或推送；`main` 与原有 `.test-tmp/`、`.workbuddy/` 保持不动。
